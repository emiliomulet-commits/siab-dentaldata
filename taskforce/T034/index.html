T034
Seguridad y red

Private Link en todos los servicios de datos

Garantizar que ningún servicio con datos es accesible desde Internet.

Semana 2 · 23–27 nov 2026Ingeniero/a de plataforma Azure2 jornadas3 dependencias · bloquea 0

Objetivo

Garantizar que ningún servicio con datos es accesible desde Internet.

Hecho cuando: FHIR, DICOM, Key Vault, PostgreSQL y Storage sin acceso público, comprobado desde fuera.

Criterios de aceptación

  • FHIR, DICOM, Key Vault, PostgreSQL y Storage con acceso público deshabilitado.
  • Endpoints privados con DNS correcto.
  • Comprobación externa documentada.

Retos tecnológicos

  • Servicios que requieren endpoints especiales (eventos, desidentificación).

Desarrollo

  1. Endpoints privados por servicio en la plantilla.
  2. Network Security Perimeter donde aplique.
  3. Script de verificación desde fuera.

Integraciones

  • Usa red (T023) y plantilla HDS (T028).

Pruebas

  • Escaneo externo: ningún puerto de datos responde.

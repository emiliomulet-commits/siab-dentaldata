T024
Plataforma Azure

Expendedora de suscripciones

Automatizar el alta de una clínica en Azure: una pull request crea su suscripción con red, etiquetas y políticas.

Semana 2 · 23–27 nov 2026Ingeniero/a de plataforma Azure2 jornadas2 dependencias · bloquea 2

Objetivo

Automatizar el alta de una clínica en Azure: una pull request crea su suscripción con red, etiquetas y políticas.

Hecho cuando: Alta de una clínica nueva = una pull request que crea suscripción, etiquetas y políticas.

Criterios de aceptación

  • Módulo de expendedora de suscripciones operativo.
  • Nueva clínica = fichero de parámetros + PR.
  • Suscripción creada con spoke, presupuesto y etiquetas.

Retos tecnológicos

  • Permisos de facturación (EA o MCA) para crear suscripciones por código.
  • Idempotencia y nombres únicos.

Desarrollo

  1. Usar el módulo sub-vending de Azure Verified Modules.
  2. Plantilla de parámetros por clínica.
  3. Presupuesto y alertas de coste por suscripción.

Integraciones

  • Usa T021 y T022; la usa T028.

Pruebas

  • Crear y borrar la clínica de prueba «clinic-000» dos veces sin errores.
